STOLAR-DB: NYNORSK LANGUAGE REQUIREMENT
========================================

ALL enrichment data (_va_enrichment.json, _nm_enrichment.json, _style_enrichment.json)
MUST be written in Nynorsk (Norwegian). Do NOT use English terms for any values.

Designer names must be kept in their original form (e.g. "Charles Eames", "Arne Jacobsen").
Only descriptions and metadata terms should be in Nynorsk.

IMPORTANT: Always use proper Unicode characters (ø, æ, å) -- never ASCII substitutes
like "oe", "ae", "aa". For example: "Stål" not "Staal", "Lær" not "Laer".

NOTES FOR AGENTS
========================================
- When writing enrichment JSON, use these Nynorsk terms, not English equivalents.
- Designer names stay in original language (do not translate personal names).
- Descriptions of designers, styles, and objects should be written in Nynorsk prose.
- If a term is missing from this list, use standard Nynorsk vocabulary.
- ALWAYS use proper Unicode: ø, æ, å -- never ASCII approximations (oe, ae, aa).
